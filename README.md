# Imperial Implant Center — Coming Soon Page

A minimal, high-performance "Website Coming Soon" landing page for **Imperial Implant Center** in Yerevan, Armenia. Built with Next.js 16 (App Router), Tailwind CSS, Framer Motion, and Aceternity Aurora Background animations.

---

## 🌟 Overview

- **Fluid Aurora Background**: Smooth emerald, teal, and mint atmospheric waves running with hardware-accelerated CSS keyframe animations.
- **Transparent Logo Presentation**: The original transparent PNG logo floats directly on the fluid aurora background with smooth entrance animation and no surrounding borders or boxes.
- **Minimal, Refined Messaging**: "Our New Website is Coming Soon" with direct contact and visiting information for the Yerevan clinic.

- **Vercel Native**: 100% optimized for zero-config instant deployment on Vercel.

## 🚀 How to Deploy on Vercel

### Option 1: Via Vercel Web Dashboard (1-Click)

1. Go to [vercel.com/new](https://vercel.com/new).
2. Select and import **`shaaraa/imp-imp`**.
3. Framework Preset will automatically detect **Next.js**.
4. Click **Deploy**. Your site will be live worldwide in under 60 seconds!

---

### Option 2: Via Vercel CLI

From the project root:

```bash
npx vercel
```

Follow the prompts to deploy to preview, or run `npx vercel --prod` to deploy to production.
